# Video Style

Target output:
- 1080x1920
- 30 fps
- H.264 MP4
- readable burned-in captions
- fast but natural pacing
- meaningful visual changes tied to narration
- real source screenshots/footage, diagrams, UI captures, or other semantically relevant assets when available
- restrained motion graphics
- no generic AI-looking cards as the primary visual language
- no black-padding portrait output
- audio must not contain unexplained long silent gaps

A professional Short should communicate the idea even with the sound muted through captions and visuals, while still preserving the original speaker's meaning.
