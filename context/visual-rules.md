# Visual Rules

For each sentence or idea, ask what visual evidence would make it easier to understand.

Priority order:
1. Relevant source footage or screen capture.
2. Real photographic/illustrative asset with a clear semantic role.
3. Purpose-built diagram or UI reconstruction.
4. Minimal kinetic typography.

Do not use decorative geometry merely because it is easy to animate.

When a concept changes, the visual treatment should change with it.
