# Visual Storyboarding Skill

## Goal
Translate the spoken idea into a shot-by-shot visual plan before rendering.

## Procedure
For each beat:
1. State the spoken claim.
2. Identify the visual evidence or metaphor.
3. Select source footage, real asset, UI reconstruction, diagram, or typography.
4. Define entrance/exit and camera movement.
5. Check that the visual changes when the idea changes.

The storyboard is an intermediate artifact. Do not render blindly from a paragraph.
