# Visual Assets Skill

## Goal
Provide semantically relevant visuals for the storyboard.

## Rules
- Prefer real source visuals and screenshots.
- Assets must be tied to a specific narration beat.
- Record provenance/path for each asset.
- Never reuse one generic image as fake B-roll for unrelated sentences.
- If an asset cannot be obtained, downgrade to a purposeful diagram or kinetic typography rather than inventing a realistic-looking fake source.

## Validation
Every asset used in a render must exist before rendering and must have a role in the storyboard.
