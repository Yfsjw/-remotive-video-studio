# Quality Control Skill

## Gate 1 — File
Check existence, size, duration, dimensions, codecs, frame rate.

## Gate 2 — Editorial
Check clip boundaries, transcript coverage, captions, and intended hook/payoff.

## Gate 3 — Visual
Inspect representative frames. Confirm visuals match the narration and are not repeated placeholders.

## Gate 4 — Audio
Confirm speech is present and no unexpected long silence dominates.

Reject and report the exact failed gate. Do not silently patch around a failed gate.
